How Does It Work?

  1. Checkbox Hack

    A hidden checkbox plus a `label[for]` toggles state - drives every modal, drawer, and menu on this site with no JS.

    CSS-Tricks - The "Checkbox Hack"

  2. Space-toggle variables

    `--on`/`--off` custom properties that are valid or guaranteed-invalid switch whole values - including keywords like `display` or `position` - without `@media`/`@container` at the point of use.

    CSS is a programming language thanks to the Space Toggle trick

  3. `:has()`

    Acts as a parent selector - style a container based on which children are checked, focused, or present.

    CSS :has() Interactive Guide

  4. Custom properties

    Every color, spacing, and border on this site is a variable, changeable at runtime - the single source of truth behind the theme switcher.

    CSS-Tricks - A Complete Guide to Custom Properties

  5. `accent-color`

    Recolors native checkboxes, radios, and range inputs to match the theme - no custom-built controls needed.

    CSS-Tricks - accent-color

  6. `overscroll-behavior`

    Stops scroll from chaining into the page behind - used right here so scrolling this panel doesn't also scroll the page underneath.

    Prevent Page Scrolling When a Modal is Open

  7. Unholy Albatross

    The `flex`/`clamp()` layout trick behind the responsive grid - columns that wrap without a single `@media` query.

    Unholy Albatross
