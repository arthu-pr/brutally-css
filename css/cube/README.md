# CUBE CSS

[Link](https://cube.fyi/)

- [Composition](./layout/)

  > Compositions create flexible layouts, helping to bring structure to whatever content they contain. [cu.css](https://cu.harrycresswell.com/compositions/)

- [Blocks](./blocks/)
  Blocks refer to the individual components that will bne used in a composition. Typically they can be:
- Button
- Card
- Form
  etc. [cu.css](https://cu.harrycresswell.com/blocks/)

- [Utilities](./utilities/)
  Utilities are small, single-purpose classes that can be used to style elements quickly and easily. [cu.css](https://cu.harrycresswell.com/utilities/)
